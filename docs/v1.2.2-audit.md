## 自动与原生检查

130/130 自动检查通过，覆盖有效零值、缓存／较旧／历史、选中可聚焦与受限不可操作、各操作阶段的提示、能力来源和就绪状态、文本比例驱动的列数、状态色与预设色差。原有协议、模式、风扇、托盘和更新检查保留。WinUI Release 构建零警告、零错误；Lucide、品牌、协议证据检查及原生后台构建检查通过。

实机浏览：本机显示缩放为 175%（XamlRoot.RasterizationScale=1.75），文本比例为 100%。2338×1211 物理像素窗口下，三列六卡的主读数和页脚完整可见；1500×1211 浅色窗口改为两列，滚动后的底部模式、风扇和入口完整可读。查看了深浅主题、当前模式选中底色／勾选／可访问性名称、无操作时不显示占位 InfoBar、紧凑设置行、提前的更新入口、四预设直接预览及单个禁用自定义入口。主题面板通过 Tab 显示焦点，并用空格选择极地微光，偏好成功保存；运行状态方案将 CPU／GPU 温度保持中性，标签明确占用率／输出的着色依据。缺失显卡状态与较旧电池状态有局部标识，无重复的全页传感器提醒。模式卡链接仅导航到性能与散热页。没有点击实机模式或风扇写入按钮。

长值与字号使用隔离的原生界面样例模拟：149.9°C、20,000 RPM、100% 及“自定义／原厂已保存”，在 175% DPI 下检查浅色三列（宽 1000 DIP）、深色两列（700 DIP）及 200% 字号的单列（700 DIP）。对六卡文本相对于卡片的实际边界测量，三种场景越界数量均为零；这不是硬件高温或高转速实测，也不是修改 Windows 全局文本比例。最终按用户要求恢复了原水印原样，以实机浅深主题对照检查最终图形，未将隔离样例误称为完整产品或协议验收。

初轮候选因新增嵌套遮罩出现 WinUI 参数异常，已回退该组合；最终水印渲染文件与 1.2.1 一致，后续启动与切页恢复正常。修正了当前模式说明文字在强调底色上的对比问题。最终便携包身份校验通过：536 个 ZIP 条目、72 个源文件身份、7 个应用二进制哈希；诊断 CLI 构建零警告、零错误。高对比度隐藏路径和操作失败／不确定阶段以代码与模型检查覆盖；未进行本轮系统高对比度切换、Narrator 或实机模式／风扇写入回归。

关窗记录为 Closed、connected=false、animationsRunning=false、glowVisuals=0；界面进程退出，仅剩原生轻量后台。模式与风扇日志的更新时间仍分别为 2026-10-22 和 2026-10-23。真实登录自启动与服务重启仍按此前用户决定不做实测。

最终视觉约束：用户明确要求恢复上一版图标背景。已将 MetricCardView.Watermark.cs 完整恢复为 1.2.1，不保留将图形压成角落色斑的激进避让遮罩。整组背景色雾、半透明卡片和用户原有配色偏好继续保留。
