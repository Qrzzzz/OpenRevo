## 范围

具体差异显示实际值和审计值。服务大小不同时也计算并记录实际哈希，核对完成前不提取认证或连接服务。增加本地审计材料保存与重新检测入口，诊断 schemaVersion 为 4；旧 schema 记录不会用于授予权限。
