# OpenRevo 1.1.2 验收记录

日期：2026-10-23。此版本扩展原生托盘快捷菜单并更换应用品牌图标，不增加厂商命令或机型范围。

## 托盘操作与生命周期

菜单分为页面入口、快捷控制、工具和退出。性能模式子菜单包含办公、均衡、狂暴和原厂已保存的自定义；风扇子菜单包含一键强冷与自动调速。连接中按现有 ModePilot 的实时授权显示禁用状态和当前选中项，可撤销最近一次模式切换或保留当前模式。另有刷新、固定位置保存诊断和 GitHub 检查更新。

后台仍使用独立 Win32 进程；没有 CLR、WinUI、硬件连接、采样计时器或联网轮询。仅在打开菜单时询问正在运行的 UI 的可用状态，200 ms 无响应时禁用控制。窗口关闭时，四模式和两项风扇操作作为一次性意图启动主程序；在可见窗口中等待初始身份／状态读取，使用现有控制策略执行并回读。请求不持久化、不排队、不自动重新连接或重放，最多等待初始状态 15 秒；连接换代或退出则不执行。结果在性能页显示，窗口保留以便核对；关窗后释放界面和监测连接。

菜单状态仅用于显示。执行前再次检查实时控制条件，最终写入仍由原有 ModePilot 的发送前核验与两次回读保护。撤销和保留仅属于当前连接的恢复记录，关窗后不继承。当前模式不重复发送。自启动保持默认关闭。

## 图标

使用内置 image_gen.imagegen 生成深石墨底板、青绿色金属涡轮图标。原始透明 PNG、完整提示词、来源说明和 SHA256 位于 assets/branding/。scripts/build-app-icon.ps1 仅作尺寸转换及 PNG／ICO 编码，不重画主体：输出 16／20／24／28／32／40／48／64／128／256 px 和 256 px 标题图像，保留原始 alpha。程序、窗口、标题和托盘使用新品牌图标；导航、控件和状态提示仍使用已固定版本的离线 Lucide 字体。

## 自动检查与验证边界

114/114 检查通过，包含整数 IPC 白名单、主程序冷启动参数、生产控制策略下的菜单可用性，以及交流电／电池、强冷、狂暴能力、过期数据和断线条件。原有模式、风扇及更新回归保留。Release 构建零警告、零错误。

原生测试通过 PerMonitorV2、十种嵌入图标尺寸、透明角、预乘 alpha、抗锯齿和高亮主体检查，以及生产菜单结构、冷启动／连接／断线的禁用状态与当前项标记。开发预览运行相同 CreateTrayMenu，已查看主菜单、四模式及风扇子菜单；预览不转发控制，不计作实机写入证明。

用户确认实机托盘验收正常：右键选择“性能与风扇”能打开正确页面，关窗后从托盘选择“检查 GitHub 更新”能重新打开并开始检查，菜单位置和清晰度均正常。该反馈覆盖实际页面意图转发、冷启动更新和托盘显示；通过托盘发起的新硬件写入尚未实测，不把预览、模拟检查或旧版本记录计作新硬件写入证明。未改变真实登录自启动跳过、服务重启仅模拟的既定范围。

本地候选成功启动，原生截图显示 1.1.2、新标题图标及实时监控；机型与后台身份匹配，初始模式为狂暴。通过设置中的退出按钮正常结束 UI 和后台，last-session.json 已更新。菜单预览与窗口检查未更改设备模式或风扇。

首轮候选后台 EXE 为 318,464 字节；两个进程快照中私有内存均为 1,658,880 字节（约 1.6 MiB），工作集均为 12,636,160 字节（约 12.1 MiB），累计 CPU 时间均为 0.03125 秒。此为本机瞬时观察，不承诺所有系统的固定占用。后台不加载 CLR 或 WinUI。
