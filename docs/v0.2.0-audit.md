# 0.2.0 验收记录

此记录区分本机证据与公开构建。0.2.0 按本机监控预览版发行；公开构建、资产校验和发布状态以对应 GitHub Actions 运行与 Release 为准，不将 CI 构建当作实机交互验收。

## 版本范围

合并原计划中 0.1.1 的稳定性维护与 0.2.0 的协议 / 能力审计。维持三种固定请求、七个精确订阅、loopback 和现有已审计机型；硬件写入保持禁用。

- 单调时间计算新鲜度、查询和心跳间隔，UTC 保留作诊断。
- 能力实时降级或 45 秒未续期后结束当前会话；无自动重连或请求重放。
- PINGRESP 独立超时，其他数据不能掩盖心跳失败。
- 类型化异常、安装识别进度、会话阶段、主题新鲜度与缺失状态进入本地诊断。
- 启动时设置 XAML 焦点；导出期间屏蔽重复 Picker；原生界面显示 0.2.0。
- 机型配置与协议证据嵌入程序集；运行时交叉核对三条请求契约。配置没有扩大适用机型。
- 还原六处可读的传输 / 消费边；八处目标业务声明仍受保护，原始 IL 已复核。详见 [关键处理链路](processing-chains.md)。
- 上传 / 下载 Action 更新为固定提交的 v7.0.2 / v8.0.2，已读取 action.yml 确认使用 node24；新增可在无厂商安装的 CI 中运行的协议目录一致性检查。
