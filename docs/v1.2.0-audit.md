# OpenRevo 1.2.0 验收记录

日期：2026-10-23。本版仅调整设备概览的卡片外观和本地界面偏好，不新增硬件控制或协议请求。

## 光效与配色

概览新增“卡片光效”入口。按用户提供的 Apple Health 背景参考，整组卡片共用大范围交叠的柔和色雾，不沿卡片边缘绘制独立光圈。卡片使用近中性、半透明的浅色渐变底与弱边框，让背景在卡片之间和卡片内部保持连续。静态光晕默认开启，动态默认关闭，提供总开关。预设为流光彩谱、赛博朋克、极地微光和玫瑰暮色。自定义仅保留一个禁用选项，并说明后续版本提供，不打开空编辑页。

状态显示使用蓝→紫→珊瑚红：CPU／GPU 按占用、风扇按占空比、电池按低电量；当前模式有效时为蓝色。高负载在 80% 后逐渐变红，95% 及以上为珊瑚红；低电量在 20% 以下逐渐变色，10% 及以下为珊瑚红。无效、过期、缓存或断线数据为灰色，不将未知值显示成正常状态。颜色辅助查看，不改变数值、时间戳或故障判定，也不构成新的设备报警。

设置与原有主题／窗口偏好共同保存在 preferences.json，独立于设备授权。旧偏好无新字段时使用静态默认值；未知枚举数值回退到预设／流光彩谱。高对比度时暂停光效并恢复系统卡片画笔。

## 动态与资源

使用六个合成径向渐变，动态仅动画化中心与透明度，不增加 UI 逐帧定时器、外部绘图库或图片纹理。动态需用户开启，且仅在概览可见、窗口未最小化并处于前台、系统允许动画时运行；切页、失去前台、最小化、高对比度或关闭光效后停止，退出时释放合成对象。产品界面提示动态会增加 GPU 使用和耗电，不宣称零成本。独立原生托盘不添加动画、设备采样或联网轮询。

诊断新增可选 appearance 字段，记录光效偏好、合成对象数量及动画是否运行，不更改现有 schemaVersion 4 字段。

实现参考微软的[合成适配指南](https://learn.microsoft.com/en-us/windows/apps/develop/composition/composition-tailoring)和[动画性能指南](https://learn.microsoft.com/en-us/windows/apps/develop/performance/optimize-animations-and-media)。

## 检查

119/119 检查通过，包含四组配色、状态色阶、低电量、失效数据、旧设置兼容和动画生命周期条件；协议、模式、风扇、托盘与更新检查保留。WinUI Release 构建零警告、零错误。

原生候选已检查浅色／深色主题下的一体式色雾、四组预设切换、状态显示、动态开关、总开关关闭后恢复普通卡片，以及重新开启。键盘方向键和 Home 可选择预设；自定义选项在可访问性树中明确禁用，说明文字可见。系统主题恢复为原偏好的“跟随系统”，光效恢复为默认流光彩谱、静态开启。

关闭最终候选后，只剩 OpenRevo.Background，last-session.json 为 Closed、connected=false、animationsRunning=false、glowVisuals=0。此时后台私有内存 1,662,976 字节（约 1.6 MiB），工作集 12,640,256 字节；只是本机快照，不是跨设备性能承诺。此前动态开启的首轮候选退出后也记录了动画停止、合成对象归零。观察期间 crash.log 未新增记录。

未修改设备模式或风扇，不为触发红色而施加硬件负载；高占用／低电量红色阈值以模拟输入验证。高对比度、系统关闭动画、失去前台和最小化的停止条件有自动检查及代码路径验证，不将它们全部写为本轮系统界面实测。未进行 GPU 耗电基准测试。
