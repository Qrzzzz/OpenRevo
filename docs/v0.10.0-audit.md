# OpenRevo 0.10.0 验收记录

实现与首轮原生验收：2026-10-22；收尾：2026-10-23。

新增默认关闭的当前用户开机自启动，设置中推荐开启；登记 Windows Run 项，登录只启动独立 Win32 托盘。关闭窗口默认保留托盘，可在设置关闭。关闭界面会结束监控连接并释放 WinUI 进程，后台不连接硬件、不运行定时采样，不恢复或重放模式。设置及托盘均可明确退出。重复启动唤起已有界面；不同目录的新版接管旧版托盘，开机启动路径更换需用户明确关闭再开启。

托盘以 MSVC 静态运行库编译，不依赖 CLR、WinUI 或额外安装运行时。事件驱动的 GetMessage 循环，处理打开、退出及 Explorer 重建托盘通知。

93/93 检查通过，包含旧偏好兼容、驻留偏好保存、带空格／中文的自启动路径、非法及过长路径拒绝、Windows 路径大小写识别。原有协议、监控与四模式检查继续通过。WinUI、CLI Release 构建及原生 C++ /W4 /WX 构建通过，无警告、无错误。协议索引仍为三种读取／采样请求、四种受限模式动作、七个订阅主题；本次未改核心硬件控制或协议数据。

## 原生交互

设置显示“开机自启动（推荐开启）”，默认关闭；首次打开设置不创建 Run 项。实际开启后，HKCU Run 的 OpenRevo 值为带引号的当前完整后台路径及 `--autostart`，无管理员权限请求；重新打开界面保持开启。实际关闭后移除该值，收尾仍保持关闭。记录见本机 `.local/evidence/v0100-startup-enabled.json`、`v0100-startup-disabled.json`。Windows“启动应用”中的禁用状态不由程序强制覆盖，界面提示由用户在那里重新启用。

首次关窗保存 Closed 状态，界面／核心计数均为 82、零异常、模式日志 Idle；WinUI 进程实际消失，只保留托盘。关闭驻留开关后托盘立即退出，偏好保存为 false；再关窗两类进程均退出。托盘打开命令重新创建界面并建立新连接，未重放模式。重复启动时主进程 PID 和窗口不变。

最终包实测将其他文件夹的后台替换为当前发行目录的后台，始终只有一个托盘进程。自启动路径不会随接管擅自修改；切换发行目录后由用户明确关闭再开启自启动。记录 `.local/evidence/v0100-final-handoff.json`。

首轮发现两处问题并修复：路径仅大小写不同被误报为其他文件夹，改为按 Windows 路径规则比较；设置／托盘明确退出直接调用 Window.Close 会绕过 AppWindow.Closing，改为发送 WM_CLOSE，复用等待连接结束、保存最终会话、停止托盘的路径。

退出修复后的最终包在设置中点击“退出 OpenRevo”，实际结束界面与托盘两个进程，生成新的 Closed／Cancelled 最终记录；界面／核心接收均为 26、零异常、模式日志 Idle，自启动项不存在。记录 `.local/evidence/v0100-final-explicit-exit.json` SHA256：`4ea45ce3a423858240df6a1c7dea592a9ff9c6823d192c59fa9a700e7bd46f72`。最终应用 DLL SHA256：`48b92869c7d8c858f9bea50ded2fed0f3678ce1acac24357cfa295c52493966d`。

## 后台资源

托盘可执行文件 135,168 字节（132 KiB）。原生依赖检查仅列出 USER32、SHELL32、KERNEL32；进程模块检查未加载 coreclr、hostfxr 或 Microsoft.UI.Xaml。关闭前的 WinUI 进程约 166 MiB 私有内存，关闭后进程完全退出，后台没有保留该界面内存。

首个后台观察窗口采集九个样本、约 122 秒，私有内存 1.45–1.47 MiB、工作集 10.87–11.25 MiB，CPU 累计时间始终 0.015625 秒。另一次七个样本、约 90 秒的观察包含关窗，私有内存 1.44–1.55 MiB、工作集 10.87–10.93 MiB，三个样本没有任何 WinUI 进程，CPU 时间未增长。线程数含系统内部线程为 1–4，程序主消息循环不使用定时器或轮询。原始样本与汇总保存在本机 `.local/evidence/v0100-background-resources.json`、`v0100-final-resources/` 及 `.local/validation/v0100-resource-summary.json`、`v0100-final-resource-summary.json`；后一组后台二进制先于最后的 UI 退出修复，最终包另行采集纯托盘样本。

最终托盘二进制 SHA256：`e229a41beca0fc4e0b37633a5bb832419a9f6798912ee4c6f0d9dd17ae79924b`。2026-10-23 对该最终二进制重新采集七个纯托盘样本，覆盖 60.28 秒，所有样本中 WinUI 进程数均为零；私有内存 1.44–1.56 MiB，工作集 10.87–10.93 MiB，CPU 时间增量为零。原始记录 `.local/evidence/v0100-idle-completed/`，汇总 `.local/validation/v0100-idle-summary.json`。此前中断的四个样本不计为完整一分钟观察。

纯托盘观察结束后，通过 `--show` 重新打开最终包，随后 `--exit` 进入托盘的整程序退出链路。主界面和后台均在等待期限内结束，保存新的 Closed／Cancelled 会话，接收计数与核心计数均为 24、零异常、模式日志 Idle；自启动仍关闭。记录 `.local/evidence/v0100-final-tray-exit.json` SHA256：`3b73156c24a195ba4a244874997777bce7a5b58d57856eef5f0bd0a033001520`。设置退出和托盘退出均未留下 WinUI 或托盘进程。

## 验证边界

原生设置开关、窗口关闭与设置退出已实测。托盘打开／退出使用程序提供的 `--show`／`--exit` 入口，进入与托盘事件相同的处理链路；自动化工具没有提供任务栏目标，鼠标点击托盘图标／菜单未自动验收。没有重启 Explorer、注销或重启 Windows，也未强制重启原厂服务；手动调用 `--autostart` 仅验证登录入口只驻留后台，不等于真实注销／登录验收。资源结论仅覆盖实际采样时段。

采用 [Windows Run 项](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)登记当前用户登录启动；托盘采用 [Shell_NotifyIcon](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyiconw)及 TaskbarCreated 通知恢复图标。程序不修改 Windows 的安全、隐私或后台服务配置。
