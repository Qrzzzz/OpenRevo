# OpenRevo 0.7.0 验收记录

日期：2026-10-22。

## 范围

仅调整前端组织、状态反馈、文案和视觉层级。控制协议、机型与配置策略、能力门槛和诊断 schemaVersion 4 不变。设计依据及具体问题见 [界面审查记录](ui-guidelines.md)。

全局连接／刷新／导出操作；概览卡片更紧凑，功耗设定按需展开；性能模式先展示当前状态，按钮等宽且按窗口宽度排列；操作与错误有独立反馈；设置与技术信息分层；原始数据采用中文来源标签并保留协议主题。

## 验证

82/82 项既有自动检查通过。最终 WinUI 编译／发布通过，未报告警告；便携包核验通过：527 个 ZIP 条目、31 项源文件身份与 3 项程序二进制身份。协议证据目录检查、Git 差异空白检查通过。源码检查确认未修改 `src/OpenRevo.Core` 或协议政策。

因初次启动的窗口处于锁定桌面，最终构建使用隔离输出 `.local/build-v070`，避免覆盖运行中的初次候选；最终便携包由同一 SDK、Release x64、自包含依赖及锁定还原参数生成，包含构建身份清单。现有 CI 构建脚本已补充界面审查文档的随包复制与必需文件核对，未执行云端 CI。

桌面解锁后完成原生验收。标准窗口下，概览指标分三列展示；性能模式先呈现当前模式／供电、操作指引和四个等宽选项。功能支持页优先展示已开放功能，其他项目和识别详情折叠显示。

紧凑窗口截图宽度约 744 像素：全局工具栏分两行，模式选择分两列，正文可纵向滚动，无横向裁切。验收发现并修复了折叠导航按钮与标题重叠，以及浅色主题全局栏背景未跟随的问题；复验通过。窗口显示模式变化会立即调整页面留白，浅／深色均使用系统主题资源。

Tab 焦点可见，Enter 可展开适用范围；保存诊断报告成功，保存路径可选择复制。原始数据中文“处理器”对应 System/CpuInfo，暂停后 JSON 保持不变；诊断记录显示后台仍继续接收处理器数据。最终修订版同时明确显示“画面已暂停”和绝对快照时间。

在性能模式页直接断开后，显示“暂时无法切换模式／请先连接设备”，四个模式按钮均禁用，顶部显示连接设备主操作。最终会话记录 schemaVersion 4、设备和文件身份均匹配、当前狂暴模式（2），模式命令数量为 0。原始 JSON 保存在 `.local/evidence/v070-final-ui-session.json`，SHA256 为 `824c874a9c8607a00c4e12a31bf4eb11afbea566aeb4cc9a89264d0eeff4766f`。
