# OpenRevo 0.5.0 验收记录

日期：2026-10-22。范围：从四模式试点转为日常操作，不新增协议命令或参数写入。当前为本地候选版本，未提交、推送或公开发布。

## 使用流程

- 直接选择另一种模式。发送前重新获取能力及配置，保存基线，只发送一次命令，等待两次一致回读。
- 可直接再次切换；新的恢复基线是最近一次切换前的配置，不是本次连接最初的模式。
- “恢复基线”要求同一连接且当前配置仍匹配确认结果，并核对所有返回配置字段。
- “保留当前模式”不发送命令，结束本次恢复记录；以后切换会建立新记录。关闭后不会将该记录误报为异常中断。
- 未选择保留或恢复便关闭时提示尚未结束；记录仅供核对，不跨连接执行恢复。旧版记录、缺少状态、未知状态、损坏及过大日志分别处理，不自动删除原始证据。

## 界面与键盘

模式按钮与保留／恢复按钮分行显示。操作中显示进度，结果独立保存，不被定时监控刷新覆盖；成功后更新旧记录提示。按钮使用标准 Tab、Shift+Tab、Enter 和空格，操作结束后焦点移到可用动作。结果文本提供礼貌级辅助功能通知。Ctrl+R／Ctrl+S 沿用刷新与导出功能。
