# OpenRevo 1.2.1 验收记录

日期：2026-10-23。本版重构设备概览的六张卡片内部排版，仅改变界面呈现。

## 排版与主题接口

参考用户提供的 Apple Health 卡片，以粗重主读数、灰色类别标题、紧贴单位及清楚的信息分组建立层级。主数字改用 44 号 Bold，模式名 40 号 Bold；收紧数字字距，取消原先上下分散、四角对齐的状态与时间。更新时间直接放在读数下方；用细分隔线隔开底部信息，标签与较粗数值成对排列。风扇 RPM 保留千位分隔，模式卡显示原厂配置来源。圆角调整为 20，采用自然内容高度。原右上角小图标改为文字层下方的 Lucide 背景水印，字号 188，以字形透明度遮罩生成柔化轮廓，并叠加斜向渐隐与圆角裁切；图形上沿和右侧部分超出卡片。水印跟随主题色，总光效关闭或系统高对比度时隐藏，无独立动画或定时器。离开页面与关窗时释放由应用创建的合成对象。缺失值保留破折号并隐藏单位。可访问性名称包含设备、数值、单位、辅助信息和历史状态；单位不作为第二个节点重复朗读。

MetricCardView 接收独立的 MetricReading 和 MetricCardTheme。主题色取自原有六路背景色，不增加一套脱节的配色；仅主要数字或模式名称着色，图标、标签、单位、占用／输出和时间使用系统中性色。强调色先大幅混入近黑／近白，保持粗体数字的明度对比，避免整组卡片出现六块粉彩标题；浅深主题分别调整强调色亮度，标准卡片底色上的对比度至少 5.5:1，为半透明色雾留有余量。缓存、过期、断线、无效或缺失读数均撤去彩色强调；关闭光效或使用系统对比度主题时恢复系统文字和卡片画笔。

保留 1.2.0 的整组连续背景色雾、四组预设、状态颜色和动画生命周期，无逐帧定时器、新协议请求或后台采样。
