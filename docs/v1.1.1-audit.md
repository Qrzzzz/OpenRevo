# OpenRevo 1.1.1 验收记录

日期：2026-10-23。本版仅统一图标和版本标识；不修改厂商通信、机型规则、风扇／模式控制或后台采样策略。

## 图标来源与覆盖

使用官方 `lucide-static` 1.61.0 npm 归档，下载后验证固定 SHA512 SRI。`scripts/vendor-lucide.py` 生成包含 18 个所需字符的 7.4 KB 字体子集、字形映射及十种独立分辨率的 ICO。原始字形不重新绘制；ICO 将官方风扇字形置于既有青绿色底板。来源、字符映射、尺寸与资产 SHA256 记录在 `assets/lucide/manifest.json`，上游完整 ISC／Feather MIT 许可在 `assets/lucide/LICENSE.txt`，发行包复制到 `ThirdPartyNotices`。

标题栏标记、五个导航入口、六张监控卡片及 InfoBar 的信息／成功／警告／错误状态改用 Lucide。导航菜单、提示关闭按钮、ComboBox 箭头和 Expander 展开／收起箭头使用同一字体。图标继承控件的前景色，装饰图标设置为可访问性 Raw 视图，按钮、链接、导航及状态文案保留原有可访问名称。Windows 系统标题栏最小化／最大化／关闭和系统文件选择器继续使用系统绘制。

应用 EXE、窗口与原生托盘共用风扇图案。托盘仍为独立 Win32 进程，按任务栏 DPI 选择 ICO 的实际尺寸，不加载 CLR、WinUI 或图标字体；PNG ICO 解码后的直通 Alpha 转换为预乘 Alpha，保持壳层合成的边缘。未增加计时器、联网或硬件连接。

## 检查与发行

`scripts/vendor-lucide.py --check` 校验固定版本、18 个字形、资产哈希、许可和旧应用符号的移除；无需安装生成工具即可在 CI 运行。生成工具 fonttools／Pillow 仅用于开发，不进入应用依赖。原生检查从托盘使用的同一嵌入式图标读取实际像素，验证 PerMonitorV2、16／20／24／28／32／40／48／64／128／256 px、透明角、抗锯齿、浅色风扇线条与预乘 Alpha。

112/112 原有协议／监控／风扇／更新检查通过，WinUI Release 构建无警告、无错误。十种图标尺寸的原生检查通过；字体二进制的家族名为 lucide，18 个映射字符均存在且具有实际轮廓。另生成两种背景的八种常见尺寸图标图样并检查，没有缺失的风扇线条。原图样保存在 `.local/evidence/v111-icon-sizes.png`。

本地便携包核验通过：534 个 ZIP 条目、56 项源码与资产身份、6 项应用／图标文件哈希，包含两项离线图标资产、来源清单和完整许可。候选包成功启动，窗口可访问性文本显示 1.1.1、导航与监控信息，原厂连接正常；随后屏幕捕获为黑色、激活失败，确认 LogonUI 正在运行，因此停止界面操作。锁屏期间未执行原生深浅色、菜单折叠、箭头切换或托盘实际点按的视觉验收；不将可访问性文本、素材预览或构建成功代替这些结果。按用户明确要求直接发布，其余自动检查与公开资产验证继续完成。

本版未新增硬件写入实测，不将模拟或既有记录改写为新的硬件验收。实际风扇／模式控制范围沿用 1.1.0。

发行沿用 Windows CI 与 Release 工作流，从标签提交重建便携包，上传草稿后下载校验 ZIP 和 SHA256SUMS，再公开为正式版。最终公开资产与运行状态见 [v1.1.1 Release](https://github.com/Qrzzzz/OpenRevo/releases/tag/v1.1.1)。
