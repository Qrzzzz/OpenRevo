# OpenRevo 1.0.0

首个正式版，面向已经验证的机械革命机型与原厂后台版本，提供硬件监控、四模式日常切换与回读、保留／撤销最近基线、原始状态和本地诊断、主题与窗口状态保存，以及轻量托盘。

开机自启动默认关闭，按需启用；保持硬件模式不需要 OpenRevo 自启动。关闭窗口默认仅保留轻量托盘并释放界面与监控连接，可在设置关闭驻留，或从设置／托盘完全退出。

托盘菜单适配屏幕缩放与所在屏幕，图标按实际尺寸平滑绘制，修正高缩放时的菜单偏移和像素感。菜单精简为打开与退出两项。

93 项自动检查及原生 DPI／八种图标尺寸检查通过；修正后的托盘位置、清晰度和操作经用户实际复验确认，另行验证了程序打开／退出入口的完整收尾。详见版本验收记录。

需保留原厂 GCUBridge／GCUService；仅支持已审计的 `YAOSHI Series-X6AR55xY`、BIOS `N.1.18MRO24` 和后台指纹组合。自定义模式调用原厂已保存配置，不编辑风扇、电池、色彩或功耗参数。此包未签名，无自动更新。

真实注销／登录自启动验证按用户要求跳过，服务重启仅模拟，未验证机型不视为兼容。完整结果和边界见 `docs/v1.0.0-audit.md`。
