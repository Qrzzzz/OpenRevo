# OpenRevo 0.9.0

进入 1.0 前的功能冻结与回归阶段。界面按每个主题的最新状态刷新，避免消息突发积压，同时保留全部接收计数和来源信息；核心控制仍逐条处理消息。完善断开过程与完成状态，避免旧通知重新显示为已连接。标题栏响应系统对比度主题，补充正式版验收范围。

监控、办公／均衡／狂暴／原厂已保存自定义配置的控制范围不变，不新增硬件参数写入、自动重连或恢复重放。实际验证和限制见 `docs/v0.9.0-audit.md`。

91 项自动检查、WinUI／CLI 构建、协议目录及便携包身份核验通过。原生候选完成约 14.5 分钟与 82.4 分钟两个独立会话，以及系统“沙漠”对比度主题及恢复、暂停画面与后台更新、Ctrl+S 导出、重复实例占用提示和断开／重连验证。最终便携包另行通过启动、断开、重连、诊断保存及正常退出复验，退出时界面与核心接收计数一致。本轮模式命令数为 0。

服务重启保留模拟验证；供电与 S0 待机沿用已有实测。资源趋势仅按实际采样时段记录，未执行屏幕阅读器实际播报与多机型验收。
