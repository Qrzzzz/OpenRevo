# OpenRevo 1.1.1

统一使用 Lucide 图标：标题栏、导航、监控卡片、状态提示、菜单及展开／收起箭头，以及程序文件、窗口和托盘图标。

图标来自固定版本 lucide-static 1.61.0，使用离线矢量字体子集，支持深浅色与系统对比度颜色。程序和托盘共用 Lucide 风扇图案，内置 16–256 px 十种尺寸，保留 DPI 适配和透明边缘处理。字体与图标随发行包提供，不依赖 CDN 或额外常驻运行库；附带上游 ISC／MIT 许可。

沿用 1.1.0 的风扇强冷、自动调速、四模式与 GitHub 更新检查，不修改硬件协议或后台轮询行为。Windows 系统标题栏按钮和系统文件选择器继续由操作系统绘制。

112 项自动检查、Lucide 资产校验、原生十种尺寸与 DPI 检查通过。候选包可启动并连接；桌面锁定使本轮原生视觉验收未完成，按用户要求直接发布，实际范围见 `docs/v1.1.1-audit.md`。
