# OpenRevo 0.10.0

增加可选的开机自启动，默认关闭，设置中推荐开启。登录后仅进入托盘，不弹出主窗口。关闭窗口可保留轻量后台，释放界面和监控连接；点击托盘重新打开，右键菜单或设置中可完全退出。

后台为独立 Win32 程序，不加载 .NET／WinUI，不采样、不改变硬件模式。增加界面和托盘单实例处理，以及便携更新时的托盘接管。实际验证与限制见 `docs/v0.10.0-audit.md`。

93 项检查、WinUI／CLI／原生后台构建及便携包身份校验通过。自启动登记／撤销、关窗释放界面、重开、关闭驻留、重复启动、后台接管、设置与托盘退出链路已验证。最终纯托盘一分钟观察中，私有内存约 1.44–1.56 MiB，工作集约 10.9 MiB，CPU 时间未增加。

没有执行真实注销／登录、Explorer 重启或托盘鼠标菜单自动验收；托盘打开与退出通过程序入口验证。
