# OpenRevo 0.6.0

完善能力与配置识别：区分机型／服务身份、实时能力和关键模式配置。蓝屏通知开关与历史恢复时间戳变化不再导致模式按钮失效；供电、配置索引、功耗／风扇配置、未知字段和版本身份继续核对。

界面显示具体不匹配字段、期望与实际值、按钮不可用原因；增加“保存审计材料”和“重新检测并连接”，不会自动信任新版本。诊断升级为 schemaVersion 4，字段分类政策随包提供并纳入证据目录。

适用机型、BIOS、后台服务及四模式控制范围沿用 0.5.0。本地验收与限制见 `docs/v0.6.0-audit.md`。

验证：82 项自动检查、WinUI／CLI 构建、协议目录与便携包核验通过；原生界面保存审计材料、重新检测，以及实机狂暴→办公→恢复狂暴通过。重新检测会话没有重放模式命令；版本不匹配及通知变化场景使用模拟验证。
