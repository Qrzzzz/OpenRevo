# OpenRevo 0.3.0

增加办公、均衡、狂暴和已保存自定义配置的受限切换试点，支持基线保存、单次切换、两次一致回读和显式恢复。恢复核对全部回报字段，异常停止后不自动重试或重放；增加本地操作日志与异常提示。

仅适用于已审计机型、后台版本、交流电及精确配置组合。已完成本机办公分别切到均衡、狂暴、原厂已保存自定义配置，再恢复办公的三个闭环，91 个回报字段恢复一致。自定义参数编辑与直接硬件参数控制仍未开放。详情见随包审计记录。

验证：60 项自动化检查通过；狂暴与已保存自定义配置完成实际 WinUI 按钮切换、回读与恢复；Windows x64 自包含便携包通过依赖、源文件身份及 SHA256 校验。
