OpenRevo 0.2.0 本机监控预览版，合并监控维护与协议证据审计。

- 能力降级或过期后终止当前连接，手动重连；传感器流量不能替代能力续期或 PINGRESP。
- 新鲜度、心跳与查询间隔改用单调时间，保留 UTC 诊断时间。
- 增加类型化错误、安装匹配报告、会话阶段与主题健康状态，改进启动焦点和重复导出处理。
- 增加嵌入式机型配置、统一协议目录和运行时契约交叉校验。
- 还原可读的发送 / 消费处理链路，区分受保护入口与已验证行为。
- 维护固定版本的 GitHub Actions，增加协议证据一致性检查。

仅适用于现有审计配置，仍需原厂 GCUBridge / GCUService。受保护业务方法体尚未恢复，未开放模式、风扇、功耗、电池阈值或色彩写入。

下载并完整解压 `OpenRevo-0.2.0-win-x64.zip` 后运行 `OpenRevo.exe`，使用 `SHA256SUMS.txt` 核对完整性。本版未签名。详细本机结果和未执行项目见包内 `docs/v0.2.0-audit.md`。
