# OpenRevo 0.5.0

四模式控制可用于连续操作：无需每次先恢复，下一次切换会以切换前的配置建立新的基线。“恢复基线”撤销最近一次切换；“保留当前模式”结束本次恢复记录，不发送硬件命令。关闭或重连不会自动恢复。

改善操作后的键盘焦点和结果提示，旧日志区分已保留、已确认切换及异常中断。失败提示保持显示，不再被监控刷新覆盖。异常后继续停止控制；设备、供电和配置支持范围沿用 0.4.0。

本地验收及限制见随包 `docs/v0.5.0-audit.md`。

验证：75 项自动检查、WinUI／CLI 构建、协议目录及便携包身份校验通过；实机连续切换、恢复最近基线、保留和重启旧日志显示通过，最终回到起始狂暴模式。
