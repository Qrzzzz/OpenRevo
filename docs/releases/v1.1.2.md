# OpenRevo 1.1.2

托盘增加常用页面、四种性能模式、一键强冷／自动调速、撤销与保留、刷新、保存诊断和 GitHub 更新检查。菜单按当前实时状态显示可用项和选中项。

关闭主窗口后，点击控制项会打开主程序，核对设备状态后执行一次并显示结果；不会在后台排队或重试。主程序关闭后仍只保留轻量原生托盘，不增加采样或联网轮询。开机自启动保持默认关闭。

应用品牌图标改为 imagegen 绘制的青绿色金属涡轮，并提供十种 Windows 图标尺寸；应用内功能图标继续使用离线 Lucide。

验证与范围见随包 docs/v1.1.2-audit.md。仅支持已审计机型、BIOS 与原厂后台组合。自定义调用原厂已保存配置；不编辑曲线、转速、功耗、电池或屏幕色彩参数。
