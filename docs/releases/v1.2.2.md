# OpenRevo 1.2.2

改善设备状态的可理解性，并让常用入口更紧凑、统一。

- 当前模式使用清楚的选中态；切换核对完成即显示“已生效，无需保存”，结束撤销记录降为次要操作。
- 状态色对应占用率、风扇输出或电量，温度保持中性；等待、较旧、缓存与历史数据分别显示。
- 收紧概览顶部，将切换模式入口放入模式卡，性能与风扇页面统一命名为“性能与散热”。
- 设置采用紧凑行与按需展开的说明；光效提供四套直接预览，并保留运行状态、自定义占位和动态开关。
- 统一字重、间距、圆角与水印显示，改善窄窗和文本放大时的布局；保留上一版确认的图标水印与融合光晕。

对应 UI Issue #1–#12。控制授权、设备识别、供电与时效限制、回读及轻量后台机制保持不变。验收边界见 docs/v1.2.2-audit.md。
