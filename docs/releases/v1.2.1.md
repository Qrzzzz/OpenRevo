# OpenRevo 1.2.1

重新设计设备概览的六张卡片，突出温度、电量、转速和当前模式。

- 粗体大读数搭配紧贴单位，更新时间集中在读数下方；辅助信息通过细分隔线归组，风扇转速增加千位分隔。
- 六张卡片共用主题色接口，与一体式背景光晕呼应，仅主要读数保留轻微色调，以近黑／近白的字色呈现。
- 浅色和深色主题分别调整读数颜色，缓存、过期、断开或缺失的数据恢复中性显示。
- 图标以放大、虚化和局部裁切的水印叠在文字下方，融入背景色。
- 保留四套预设、状态配色和可关闭的动态光效，高对比度时使用系统颜色。

本版仅调整概览显示，不新增硬件请求、控制或后台轮询。验证范围见 docs/v1.2.1-audit.md。
