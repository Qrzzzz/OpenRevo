# OpenRevo 1.1.0

新增原厂一键强冷控制，以及从 GitHub 检查正式版更新。

- 在性能模式页开启一键强冷或恢复自动调速，操作后以两次新鲜状态回读确认，并显示 CPU／GPU 风扇 RPM 与占空比。已在本机办公、均衡、狂暴及已保存的自定义模式下验证开关和配置恢复。
- 模式切换与风扇操作共用操作锁，重复点击不会排队；正常强冷状态不再被误判为未知配置。切换模式前先恢复自动调速，风扇操作会结束此前的模式撤销记录。
- 设置与诊断新增“检查更新”，显示最新正式版本、发布说明和便携包下载入口。API 限流时通过 GitHub 官方最新发布地址确认版本并提供发布页入口。网络故障和超时可手动重试，下载交给浏览器，不自动安装或覆盖旧版。
- 风扇仍由原厂后台管理，关窗与断线不自动恢复或重放命令。轻量托盘未增加温控循环、更新检查计时器或网络连接；开机自启动继续默认关闭。

仅支持已验证的主板、BIOS 与原厂后台组合；风扇曲线、手动占空比、电池阈值、色彩和功耗参数编辑仍未开放。下载后完整解压；更新前从托盘完全退出旧版。

112 项自动检查、原生 WinUI／CLI 构建、原厂及独立服务协议回读分别记录于随包 `docs/v1.1.0-audit.md`。服务重启仍仅模拟，真实登录自启动按用户决定跳过。
