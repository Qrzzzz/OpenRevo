OpenRevo 首个 Windows 11 原生监控预览版。

## 功能

- 识别已审计的本机主板、BIOS、厂商服务版本与能力位。
- 展示 CPU/GPU 温度与占用、两路风扇转速和占空比、电量与供电、模式及原始功耗配置。
- 提供原始主题 JSON、暂停显示、刷新、断开重连、本地诊断导出和浅深主题。
- 分别标记未知、缓存、旧数据与断开后的历史值；保留厂商返回的 TGP 范围矛盾。

## 使用

下载 `OpenRevo-0.1.0-win-x64.zip`，完整解压后运行 `OpenRevo.exe`。无需另装 .NET 或管理员权限，可用 `SHA256SUMS.txt` 检查下载完整性。

仅适用于本次审计的 MECHREVO `YAOSHI Series-X6AR55xY`、BIOS `N.1.18MRO24` 及匹配指纹的厂商后台。仍需原厂服务；不匹配的机器或版本会停止连接。本版未签名。

## 验证与边界

核心协议与状态检查 29/29 通过。本机已实际验证 WinUI 界面、导航、主题、原始状态暂停恢复、刷新、断开重连及诊断保存。CI 重新构建并验证便携包，未将云端测试当作硬件验收。

本版仅开放状态读取及启用厂商共享监控采样的固定请求。屏幕色彩、风扇曲线、电池阈值、功耗、超频和独显切换写入未开放。厂商核心服务的受保护方法体尚未完整还原，本版没有替代原厂后台。
