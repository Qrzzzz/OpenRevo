# OpenRevo 0.10.0 本机候选版

解压整个文件夹，运行 `OpenRevo.exe`。无需另装 .NET 或使用管理员权限。需保留原厂控制中心后台服务，目前仅支持已经验证的机械革命 YAOSHI 机型、BIOS 和后台版本。

## 常用操作

- 顶部连接栏：连接或断开设备、刷新数据、导出诊断。在任意页面均可使用。
- 设备概览：查看温度、风扇、电量和当前模式。未更新或断开后的数据会标记为历史数据。
- 性能模式：切换办公、均衡、狂暴或原厂已保存的自定义配置。切换需接通电源；当前模式会单独标记。
- 功能支持：查看已开放功能，展开查看尚未开放的项目。
- 原始数据：选择数据来源，暂停画面更新后可选择和复制 JSON；后台监测会继续。
- 设置与诊断：选择主题、查看设备版本、保存报告或重新检测连接。主题会自动保存，窗口关闭后会记住位置、大小及最大化状态；显示器变化后会调整到可见范围。

`Ctrl+R` 刷新，`Ctrl+S` 导出诊断。`Tab` / `Shift+Tab` 移动焦点，`Enter` / 空格操作按钮。

监控画面通常每秒显示一次各来源的最新状态，原厂推送频率与各传感器不同。原始数据页暂停只冻结画面，后台仍持续接收；切换到其他页面再回来不会停止连接。

## 启动与后台

“设置与诊断 → 启动与后台”中的开机自启动默认关闭，推荐按需开启。开启后在当前用户登录 Windows 时只运行托盘，不弹出主窗口，无需管理员权限。若在 Windows“启动应用”中禁用，还需在那里重新启用。

关闭窗口默认保留轻量托盘，可关闭“关闭窗口后驻留托盘”改为完全退出。托盘不连接设备、不运行监控采样；关窗会结束连接、保存最终会话并释放界面进程，当前硬件模式继续有效。点击托盘重新打开并读取实时状态。托盘右键菜单或设置中的“退出 OpenRevo”会结束整个程序，不更改自启动偏好。

自启动使用当前文件夹中的 `OpenRevo.Background.exe`，请保留完整文件夹。更新前从托盘完全退出旧版；若换了文件夹，进入新版设置关闭再开启自启动，改用新位置。停用自启动后再删除不用的版本。

## 保留与撤销

切换后可以继续选择其他模式，也可以“保留此模式”来结束本次恢复记录。“撤销上次切换”只恢复最近一次切换前的模式与配置，不是恢复出厂设置。关闭、断线或重连不会自动恢复或重放命令。

自定义模式仅使用原厂已保存的配置。风扇曲线、充电限制、屏幕色彩、功耗及超频参数暂不支持编辑。结果无法确认时，请在原厂控制中心核对当前模式。

## 诊断与适用范围

“导出诊断”可选择保存位置；“保存诊断报告”写入 `%LOCALAPPDATA%\OpenRevo\audit-review.json`。关闭窗口会保存同目录下的 `last-session.json`。诊断 schemaVersion 为 4，不包含认证口令，不自动上传。

导出时会禁用重复操作，完成后回到“导出诊断”按钮。取消不会生成新文件；保存失败时可换一个可写的位置，或使用设置页的固定位置报告。退出会先结束监测连接，再保存最终会话；不会停止原厂后台。

版本不匹配时，到设置与诊断展开设备详情。恢复到受支持版本后可以重新检测；新版本仍需独立验证。具体范围见 `docs/reaudit.md`。

当前支持 Windows 11 x64、主板 `YAOSHI Series-X6AR55xY`、BIOS `N.1.18MRO24` 和匹配指纹的 GCUBridge／GCUService。当前后台基线为安装器登记版本 `5.56.51.44`，最终以文件指纹为准。其他机型或后台版本尚未验证。

## 更新与回退

先关闭旧版，再将新版完整解压到独立文件夹运行。不要将新旧版文件混合覆盖，也不要同时运行两份监测连接。回退时完整解压旧版运行；主题和窗口状态保存在 `%LOCALAPPDATA%\OpenRevo\preferences.json`，与程序文件及硬件恢复记录分开保存。设置文件缺失或无法读取时使用默认界面设置，不影响设备校验。

验收状态和未执行项目见 `docs/v0.10.0-audit.md`，正式版范围见 `docs/v1.0-acceptance.md`。0.10 增加启动与托盘机制，不扩展硬件控制范围。此包未签名，公开发布见 https://github.com/Qrzzzz/OpenRevo/releases 。
