# OpenRevo 0.6.0 本机预览版

解压整个文件夹，双击 `OpenRevo.exe`。请保留文件夹内所有运行文件。无需安装 .NET 或管理员权限。

本版使用 Windows 11 原生 WinUI 3，提供本机识别、CPU/GPU 与风扇监控、电量、当前模式、能力清单、原始状态及本地诊断导出。

仅适用于本次审计的 MECHREVO YAOSHI 主板、BIOS 与厂商服务版本。仍需安装并运行原厂控制中心后台；程序不会替代或卸载其服务。版本不匹配时会停止连接。

数据尚未收到时显示“—”；缓存、旧数据、断开后的历史值会分别标记。个别主题可能只在数据变化时推送，时间变旧不等同于硬件故障。点击刷新可重新查询配置并请求监控采样。

能力响应不再匹配、45 秒未续期或心跳响应超时后会结束连接，需要手动重新连接。新鲜度按单调时间计算；“连接与外观”显示会话阶段和诊断，导出包含安装匹配与主题健康状态。

本版不开放风扇曲线、电池阈值、屏幕色彩、功耗或超频写入。厂商返回的配置值不代表实时功耗。

- `Ctrl+R`：刷新。
- `Ctrl+S`：将诊断保存为本地 JSON，不含认证信息。
- “连接与外观”：查看本机识别信息、切换应用主题。

监测会启用厂商后台的共享采样计时器。断开只结束本应用连接，不发送全局停止请求。关闭窗口会在 `%LOCALAPPDATA%\OpenRevo\last-session.json` 保存最后一轮本地诊断。

本版验证范围及未执行项目见 `docs/v0.6.0-audit.md`，重新审计见 `docs/reaudit.md`，关键链路见 `docs/processing-chains.md`，统一目录见 `protocol/registry.json`。此包为未签名预览构建，后续版本见 https://github.com/Qrzzzz/OpenRevo/releases 。

“模式控制”仅在已审计的交流电和关键配置基线下开放四模式切换。自定义使用原厂已保存的配置；配置索引或参数变化后需要重新审计。切换会联动风扇和功耗配置；恢复需单独点击，并要求同一连接中两次一致回读、关键配置回到基线。断线或结果不确定时停止控制，请用原厂界面核对。重启后仅提示旧记录，不重放命令。日志位于 `%LOCALAPPDATA%\OpenRevo\mode-pilot-journal.json`。

0.6.0 将机型／服务身份、能力与配置分层。通知与历史时间戳变化不再影响模式配置指纹，供电仍单独约束控制。连接与外观显示具体版本差异，可保存审计材料到 `%LOCALAPPDATA%\OpenRevo\audit-review.json`，供独立重新审计；重新检测不会自动信任新版本。当前诊断 schemaVersion 为 4。

0.5.0 支持连续切换；每次以切换前配置作为最近恢复基线。选择“保留当前模式”仅结束本次恢复记录，不发送命令；“恢复基线”撤销最近一次切换。Tab／Shift+Tab 移动焦点，Enter／空格操作按钮。

0.4.0 增加会话及主题统计、传感器未更新提示、AC/DC 和睡眠事件记录。传感器静默时仍可查看其他状态并点击刷新；收到传统睡眠通知时结束连接，唤醒后手动重连；联网 S0 待机连接正常时继续监测。电池供电下模式按钮不可用，但监测保持可用。诊断 schemaVersion 为 3。
