# OpenRevo 1.0.0 验收记录

日期：2026-10-23。

## 定版范围

1.0 为已审计主板 `YAOSHI Series-X6AR55xY`、BIOS `N.1.18MRO24` 及匹配的原厂后台提供监控、办公／均衡／狂暴／原厂已保存自定义配置的切换、回读、保留和最近基线撤销，以及原始数据、诊断、主题／窗口偏好和轻量托盘。继续依赖 GCUBridge／GCUService；不宣称其他机型兼容，也不编辑风扇曲线、电池阈值、色彩或功耗参数。

开机自启动不是维持硬件模式的必要条件。按用户要求保持默认关闭，删除设置中的“推荐开启”，改为按需启用。真实注销／登录验证明确跳过；保留 0.10.0 的启动项登记／撤销与启动入口证据，不将它们等同于真实登录实测。

## 既有证据

四模式控制、能力／配置门槛与恢复沿用 0.3–0.6；AC/DC 与本机 S0 沿用 0.4，服务重启按用户要求保留模拟。0.9 两个原生会话约 14.5／82.4 分钟，覆盖暂停、导出、主题、断开／重连及退出。0.10 托盘为独立 Win32 程序，关闭窗口后释放 WinUI 和监控连接，实测纯托盘私有内存约 1.44–1.56 MiB、工作集约 10.9 MiB，一分钟内 CPU 时间未增加；此观察不代表多日稳定性证明。

## 最终检查

最终源码 93/93 自动检查通过；WinUI／CLI Release 构建和原生后台构建通过，无警告、无错误。协议目录仍为三种固定读取／采样请求、四种受限模式动作、七个订阅主题。修复后的便携包核验通过：529 个 ZIP 条目、42 项源码身份、四项应用二进制身份。自启动项不存在，继续默认关闭。

首轮用户实际操作报告：打开、关窗回托盘及右键退出功能本身可用，但菜单错位且有像素感，因此未据此发布。首个实际图标打开的会话记录为 1.0.0／Closed，接收六条消息，原始记录 `.local/evidence/v100-first-manual-session.json`。界面工具未返回任务栏目标，因此实际点按由用户在本机完成。

检查发现独立托盘没有声明 DPI 感知，固定 32 像素图标也没有抗锯齿。新增嵌入式 PerMonitorV2 与系统视觉样式 manifest；菜单所有者移动到触发屏幕，使用托盘屏幕坐标、图标排除区域及工作区约束定位。删除菜单中的技术状态行，仅保留打开和退出。图标按任务栏 DPI 生成，8×8 子采样产生平滑边缘和预乘透明度；DPI／显示设置变化时刷新图标，不增加轮询或常驻图形框架。

原生检查验证实际进程默认 DPI 为 PerMonitorV2，并覆盖 16、20、24、28、32、40、48、64 八种物理像素尺寸的透明角、抗锯齿边缘、白色字形与预乘 Alpha。检查加入发布构建，在 CI 中一并执行；构建为 manifest 嵌入补齐 Windows SDK 工具路径。

用户对修复版实际复验后确认“位置、清晰度和操作均正常”。这是用户实际操作反馈，不以命令模拟代替视觉验收。核对时托盘仍在运行，且未发现修复后的新会话报告，因此另外执行 `--show`／`--exit` 核验收尾，并分别记录证据范围。额外回归生成新的 1.0.0／Closed／Cancelled 会话，界面与核心接收计数均为八，零异常，模式日志 Idle；WinUI 与托盘进程均已结束，自启动项仍不存在。该命令入口记录 `.local/evidence/v100-final-tray-command-session.json` SHA256：`ff24ecffc91ec0499cf5a69d343c0a69323f119ece9b39fd0f59ebc4da33f1e3`。

修复版托盘的资源快照为约 1.48 MiB 私有内存、11.24 MiB 工作集、累计 CPU 0.046875 秒，记录 `.local/evidence/v100-dpi-tray-resource.json`。这是一时点快照；持续观察沿用上文 0.10.0 范围，不冒充修复版长时资源测试。

## 发行核验

版本号与标签固定为 1.0.0／v1.0.0。最终发布通过现有 Windows CI 和 Release 工作流重建；原生 DPI／图标检查属于打包步骤。发布脚本先上传草稿中的 ZIP 与 SHA256SUMS.txt，下载两项资产核对 SHA256 后才公开发布。云端发行包与本机候选分别构建，其二进制哈希不要求相同；发行包按上传／下载校验以及构建清单与对应提交的源码身份核验。

发布运行结果与公开资产参见 [v1.0.0 Release](https://github.com/Qrzzzz/OpenRevo/releases/tag/v1.0.0) 及对应 Actions 记录，不把本地检查写成云端运行结果。

## 已接受的限制

未签名的 Windows 11 x64 自包含便携包，无安装器或自动更新。未验证其他机型、屏幕阅读器实际播报及 Explorer 重启后的图标恢复；实际执行范围分别说明。真实登录自启动按用户决定跳过，服务重启仅模拟。后台只负责托盘和唤起界面，不接管原厂服务或持续采样；重新打开不会重放模式命令。
